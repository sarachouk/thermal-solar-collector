# Thermal Solar Collector – SolTrace Analysis

A Python-based ray-tracing analysis project for evaluating the optical performance of a solar thermal collector using simulation data exported from **SolTrace**.

## Project Overview

This project analyzes ray-tracing data generated by SolTrace to evaluate the optical performance of a parabolic trough solar collector.

The Python script processes the exported ray data to calculate optical efficiency (intercept factor) and generate visualizations of ray distribution, receiver interception, and incidence angles.

## Requirements

Python 3 is required.

Install the necessary libraries:

```bash
pip install pandas numpy matplotlib
```

## Usage

Run the analysis script from the terminal:

```bash
python finii.py raydata.csv
```

### Advanced Usage

To calculate optical efficiency and estimated collected power:

```bash
python finii.py raydata.csv --show --nsun 10000 --dni 1000 --mirror-area 0.25
```

## Command-Line Arguments

| Argument | Description |
|---|---|
| `csv` | Path to the SolTrace ray-data CSV file |
| `--show` | Display plots interactively |
| `--nsun` | Number of launched sun rays |
| `--dni` | Direct Normal Irradiance (W/m²) |
| `--mirror-area` | Aperture/mirror area (m²) |
| `--outdir` | Output directory (default: `soltrace_results`) |

## Generated Outputs

The script generates visualizations and data files to help evaluate the collector's optical performance:

1. Ray hits per stage and element.
2. Cross-sectional ray-hit distribution (X–Z).
3. Receiver hit map (X–Y).
4. Two-dimensional flux distribution.
5. Circumferential and polar flux profiles.
6. Incidence angle distributions.
7. Filtered receiver-hit data (`receiver_hits.csv`).

## Tools & Technologies

## Project Goal

To investigate the optical performance of a solar thermal collector, identify optical losses, and evaluate how effectively reflected solar radiation is concentrated onto the receiver.
